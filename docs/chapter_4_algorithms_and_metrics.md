# CHAPTER FOUR: IMPLEMENTATION AND EVALUATION

This chapter outlines the experimental setup, algorithms, and evaluation metrics used to conduct the comparative robustness study of crop disease detection models. The implementation relies on the PyTorch framework for deep learning and the IBM Adversarial Robustness Toolbox (ART) for executing attacks and defenses.

## 4.1 Algorithms and Architectures

The project investigates robustness by contrasting two prominent Convolutional Neural Network (CNN) architectures and evaluating them under specific adversarial threat models and defense mechanisms.

### 4.1.1 Classification Architectures
1. **ResNet-50**: A deep residual network that utilizes shortcut connections to bypass standard layers, alleviating the vanishing gradient problem. It represents a widely used, high-capacity baseline for computer vision tasks. The model is initialized with ImageNet weights, and its fully connected layer is modified to output 38 classes corresponding to the PlantVillage dataset.
2. **EfficientNet-B0**: A parameter-efficient architecture that uses a compound scaling method to balance network depth, width, and resolution evenly. It serves as the secondary architecture to test if a parameter-efficient model behaves similarly to a high-capacity model under adversarial conditions.

### 4.1.2 Adversarial Attack Algorithms
The threat model assumes a white-box scenario where the attacker has full access to the model's parameters and gradients.
1. **Fast Gradient Sign Method (FGSM)**: A single-step evasion attack that uses the gradient of the underlying model to generate adversarial examples. It calculates the gradient of the loss with respect to the input image and perturbs the image by a fixed step size ($\epsilon$) in the direction that maximizes the loss.
   - *Equation*: $x_{adv} = x + \epsilon \cdot \text{sign}(\nabla_x J(\theta, x, y))$
2. **Projected Gradient Descent (PGD)**: An iterative and more powerful extension of FGSM. It takes multiple smaller steps in the direction of the gradient and projects the perturbed image back into the valid $\epsilon$-ball around the original image after each step. PGD is considered a universal first-order adversary.

### 4.1.3 Defense Algorithms
1. **Adversarial Training**: A proactive defense where the model is explicitly trained on a mixture of clean images and adversarial examples (typically generated via PGD). This forces the model to learn robust features rather than relying on brittle, non-robust patterns.
2. **Input Preprocessing (Feature Squeezing)**: Non-differentiable transformations applied to the input images before classification to disrupt the carefully crafted adversarial noise.
   - *JPEG Compression*: Compresses the image to discard high-frequency noise commonly introduced by adversarial attacks.
   - *Gaussian Smoothing*: Applies a Gaussian blur filter to smooth out pixel-level perturbations.

## 4.2 Evaluation Metrics

Relying solely on clean accuracy is insufficient for evaluating model reliability. The following metrics are implemented to provide a comprehensive robustness assessment across multiple perturbation budgets ($\epsilon = 0.01, 0.03, 0.05$).

1. **Clean Accuracy ($Acc_{clean}$)**
   - *Definition*: The classification accuracy of the unmodified model on original, unperturbed test images.
   - *Purpose*: Establishes the baseline performance of the architecture on the PlantVillage dataset.

2. **Adversarial Accuracy ($Acc_{adv}$)**
   - *Definition*: The classification accuracy of the model when evaluated on adversarial examples generated by FGSM or PGD at a specific $\epsilon$.
   - *Purpose*: Measures the model's vulnerability to direct gradient-based attacks.

3. **Robustness Gap**
   - *Definition*: The absolute drop in performance caused by the attack, calculated as $Acc_{clean} - Acc_{adv}$.
   - *Purpose*: Quantifies the exact cost of the adversarial perturbation, highlighting how much performance degrades under threat.

4. **Recovery**
   - *Definition*: The adversarial accuracy of the model *after* a defense (e.g., JPEG compression or Adversarial Training) is applied, or specifically the difference between the defended adversarial accuracy and the undefended adversarial accuracy.
   - *Purpose*: Evaluates the effectiveness of the chosen defense algorithm in neutralizing the attack.

5. **Clean-Accuracy Retention**
   - *Definition*: The classification accuracy of the *defended* model when evaluated on *clean, unperturbed* images.
   - *Purpose*: Measures the robustness-accuracy trade-off. Many defenses (like smoothing or adversarial training) inherently reduce the model's ability to classify clean images correctly. High clean-accuracy retention indicates an ideal defense.
